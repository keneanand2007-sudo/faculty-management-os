# 🎓 Faculty Management OS (Academic Monitoring System)

> A modern, responsive web application designed to streamline academic planning, faculty monitoring, timetable management, and reporting for higher educational institutions.

---

## 🚀 About The Project

**Faculty Management OS** is a comprehensive frontend dashboard built to digitize and simplify day-to-day academic operations. It provides dual-role access (HOD / Master Admin and Individual Faculty) with interactive modules for lesson planning, attendance tracking, timetable management, academic events, notes sharing, and detailed graphical analytics.

---

## 🛠️ Tech Stack

* **Framework:** React 19 (Vite)
* **Styling:** Tailwind CSS v4
* **Routing:** React Router DOM
* **Icons:** Lucide React
* **Data Visualization:** Recharts
* **Data Export:** SheetJS (`xlsx`)

---

## ✨ Key Features & Modules

### 👨‍💼 HOD / Master Dashboard
* **Overview Analytics:** Real-time summary cards, charts for faculty progress, and upcoming institutional functions[cite: 2].
* **Faculty Directory:** Grid view of faculty cards, quick profile inspection, CSV data export, and new faculty onboarding[cite: 2].
* **Class & Subject Management:** Detailed student and subject allocations[cite: 2].
* **Timetable & Events:** Comprehensive Monday-to-Saturday schedule view, interactive calendar toggle, and event organizers[cite: 2].
* **Leave & Attendance Control:** Approve/reject leave requests and monitor attendance logs[cite: 2].
* **Reports & Deep Analytics:** Multi-parameter academic reporting and tabbed analytical insights[cite: 2].

### 👩‍🏫 Faculty Workspace
* **Personalized Dashboard:** Quick view of assigned subjects, timetable matching, and daily lectures[cite: 2].
* **Lesson Planning & Topics:** Break down subjects into structured lesson units, track progress, and manage notes[cite: 2].
* **Classroom Activities & Attendance:** Mark attendance, create classroom tasks, and apply for leaves[cite: 2].
* **Global Navigation:** Smart search across entities (courses, faculty, topics) and notification bell alerts[cite: 2].
